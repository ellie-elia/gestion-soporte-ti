# 04 — Evidencias

Capturas de pantalla, fotografías y archivos que demuestran lo realizado.

**Qué va aquí:**
- Capturas de pantalla (antes / durante / después).
- Fotografías del equipo físico cuando aplique.
- Archivos de salida de comandos, logs, exports.
- Cualquier cambio efectuado documentado con evidencia visual.

> _Nombrar archivos de forma clara, por ejemplo:_
> `01-estado-inicial-bios.jpg`, `02-comando-ping-fallido.png`, `03-cable-red-dañado.jpg`.
